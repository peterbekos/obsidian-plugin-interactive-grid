# Changelog

## 1.1.0

**If you created grids in 1.0.0**, open each affected note and run **Interactive Grid: Convert legacy grid blocks in current note** from the Obsidian command palette. The command changes only the opening fence label, so your card content, colors, and positions are preserved. You can also change the opening label from `grid` to `interactive-grid` manually in Source mode.

Interactive Grid now uses the `interactive-grid` fence to avoid conflicts with other plugins. Legacy `grid` blocks need the one-time conversion before they render in Interactive Grid. If you haven't made a grid yet, use `interactive-grid` for your first one.
